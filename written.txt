2a. With batching my FPS converged around 360, and with main_nobatch.cpp, it converged around 238 FPS, which means that batchig was 1.5x faster. This happens because batched version does everything in one draw call but non-batched version does individual draw calls for each sprite in every frame.

2b. Each sprite can be given a depth (z) value put in gl_Position.z in vertex shader instead of 0 and then depth testing can be turned on with glEnable(GL_DEPTH_TEST). This will let GPU check the depth at every pixel and only keep closest things, so sorting sprites is not needed. One problem is see through pixels still block sprites behind them so they have to be discarded in fragment shader.
